🌐 Modo Proxy (Kimi via Cloudflare)

Requiere un proxy gratuito en Cloudflare Workers. Las imagenes y datos se envian automaticamente a Kimi.

1. Obten API key en platform.moonshot.ai
2. Despliega el proxy (codigo adjunto)
3. Pega aqui la URL del proxy

🔷 Modo Gemini (Gratuito)

Usa la API gratuita de Google Gemini. Funciona directo desde el iPhone sin backend.

1. Ve a Google AI Studio
2. Crea una API key gratuita
3. Pegala aqui (se guarda solo en tu telefono)
